# Momhandmade. 客製選色與線上訂購

阿母手作編織的選色、訂購與賣家管理頁。買家選款式和毛線色號、加入訂購車、填超商或自取與匯款後五碼。賣家在後台看訂單、回覆留言，並和 Google 試算表同步、寄信通知。

這份網站是靜態檔，可直接放到 GitHub Pages。路徑都是相對位置，專案網站網址若是 `使用者.github.io/mamahand/` 也能開。

## 在自己的電腦看

在這個資料夾開終端機，執行：

```bash
python3 -m http.server 47321
```

然後用瀏覽器打開 `http://127.0.0.1:47321/` 。不要用檔案總管直接點 `index.html`，否則商品照片讀不到。

## 上傳到 GitHub Pages

1. 用後台「更新網站」下載壓縮檔，或使用這整份資料夾。
2. 解壓後，把 `index.html`、`css`、`js`、`images`、`gas`、`favicon.svg`、`.nojekyll` 放進儲存庫根目錄，覆蓋舊檔。
3. GitHub 儲存庫 Settings → Pages，分支選 `main`，資料夾選根目錄。

不要把後台密碼、GitHub 權杖寫進任何檔案再上傳。

## 賣家要自己做的安全步驟

舊網站把後台密碼和一組 GitHub 個人存取權杖，明文放在網頁和公開的試算表裡。靜態網頁沒辦法單獨擋住有心人，下面幾步要你親自做，做完才算鎖上。

1. 打開 GitHub → Settings → Developer settings → Personal access tokens，把舊網站裡那組權杖撤銷。不要再貼回網頁。
2. 打開 Google 試算表，右上角「共用」改成只有自己可以看。試算表一旦公開，以後的客人電話、地址、信箱都會被看見。
3. 打開這個試算表綁定的 Apps Script，用 `gas/Code.gs` 整份覆蓋。
4. 在編輯器執行「清除試算表裡的密碼與權杖」。
5. 打開函式「設定賣家密碼」，暫時填入一組新密碼（至少 10 碼，含英文、數字、符號），執行一次。執行完立刻把程式裡的密碼刪成空字串，再按存檔。密碼只會以雜湊存在指令碼屬性，不會寫回試算表。
6. 部署為網路應用程式：執行身分選自己，誰可以存取選所有人，版本選新版本。若網址有變，到網站後台「商店設定」貼上新網址並儲存。
7. 用新密碼登入後台確認看得到訂單。之後要改密碼，登入後台填「新密碼」兩格即可，不必再改程式碼。

在 Apps Script 還沒部署完成前，這個網站仍用檔案裡的密碼雜湊讓你登入（不是明文）。雜湊擋得住順手查看原始碼的人，擋不住有意修改網頁的人。部署完成後，登入改由 Apps Script 判斷，檔案裡的雜湊就不再用來放行。

閒置 20 分鐘會自動登出。連續密碼錯誤會先鎖 2 分鐘，再拉長到 15 分鐘、60 分鐘。這只限制同一台瀏覽器；Apps Script 部署後，伺服器也會另外計算錯誤次數。
